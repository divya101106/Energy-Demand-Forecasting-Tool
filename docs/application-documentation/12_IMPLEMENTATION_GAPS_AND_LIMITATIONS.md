## 2. Detailed Technical Limitations & Edge Cases

### 1. Historical Dataset Cutoff (2020-09-30)
- **Current Behavior:** The OPSD Germany load archive concludes on **September 30, 2020**.
- **Impact:** All forward forecasts generated by `POST /api/v1/forecast` project out-of-sample forward starting from **October 1, 2020**.
- **Governance:** The tool must **never be represented as forecasting live 2026 demand**. It represents a historical forward extrapolation illustrating how the 2015–2020 grid structure anticipated upcoming autumn and winter loads.

### 2. Anomaly Modal Acknowledgment State Persistence
- **Current Behavior:** On the **Anomaly Alerts** page (`/anomalies`), clicking an anomaly card opens a detail modal with an **Acknowledge Event** button.
- **Limitation:** Clicking this button sets local React state (`setSelectedAnomaly(null)`), closing the modal dialog. However, because the backend relies on fast in-memory singletons rather than an external database, the acknowledgment status is not written back to `detected_anomalies.csv`. Reloading the page resets all 96 anomalies to `Active`.

### 3. Forecast Seasonality & Holiday Checkboxes vs. Pre-Trained Artifact
- **Current Behavior:** On the **Generate Forecast** page (`/forecast`), users can toggle checkboxes for `Weekly Seasonality`, `Yearly Seasonality`, and `Holiday Effects`.
- **Limitation:** The backend model is a pre-trained, serialized Stan artifact ([`prophet_model.json`](file:///Users/dibbi/Desktop/OJT%20sem%205/Energy-Demand-Forecasting-Tool/backend/models/prophet_model.json)) fit with all components enabled. Deserialized Prophet models cannot dynamically disable Fourier series without full refitting (which takes 5–10 seconds). The backend currently modulates the uncertainty flexibility scale according to user inputs rather than refitting the Stan matrix on the fly.

### 4. Intra-Day (Hourly) vs. Daily Aggregated Granularity
- **Current Behavior:** While the raw archive ([`data/raw/time_series_60min_singleindex.csv`](file:///Users/dibbi/Desktop/OJT%20sem%205/Energy-Demand-Forecasting-Tool/data/raw/time_series_60min_singleindex.csv)) contains 50,401 hourly observations, the production forecasting pipeline operates on the daily 24-hour mean load (`opsd_daily.csv`, 2,100 records).
- **Impact:** The system cannot model intra-hour transmission dispatch (e.g. 15-minute ramping or 60-minute evening lighting peaks). It is optimized for multi-day resource adequacy.

### 5. Absence of Exogenous Weather Regressors
- **Current Behavior:** Prophet forecasts load purely as a function of time ($t$), decomposing trend, calendar seasonality, and statutory holidays.
- **Impact:** The model does not ingest external temperature, wind speed, or solar irradiance time series. Unprecedented sudden temperature swings (such as unseasonal Siberian cold snaps) appear as unexplained residual errors rather than being absorbed by temperature regressors.
